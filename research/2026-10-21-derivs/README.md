# 3차 실험: 펀딩비·미결제약정·롱숏 비율 + 코인 10개 + 통합 모델

2차 실험(`research/2026-10-20-90d-backtest/`)의 결론은 "실전 근거 없음"이었다.
지표+사건 모델의 판별력(AUC)이 0.51 안팎이라 동전 던지기와 거의 같았다.
3차는 사용자 선택 2번("학습 재료 늘리기")을 실행한다. 바뀌는 것은 세 가지다.

1. **포지션 데이터 추가**: 펀딩비, 미결제약정(OI), 롱숏 비율, 테이커 매수·매도 비율.
2. **코인 5개에서 10개로**.
3. **코인별 모델 대신 10개 코인을 함께 배우는 모델 하나**: 학습 행이 약 10배로 는다.

## 미리 정해 둔 규칙 (결과를 보기 전에 고정)

| 항목 | 내용 |
|---|---|
| 코인 | 비트겟 30일 거래대금 순서대로 내려가며 고른다. 조건은 두 가지: 비트겟에 2022-01-01 1시간봉이 있어야 하고, 바이낸스에 2022-01-01 포지션 데이터가 있어야 한다. 10개에서 멈춘다(`select_pairs_c.py`). |
| 포지션 데이터 출처 | 바이낸스 USDT-M 공개 자료다(data.binance.vision 5분 자료, fapi 펀딩 기록). 비트겟은 펀딩 기록이 최근 100건뿐이고 OI·롱숏 기록이 없어서 바이낸스를 썼다. 시장 전체의 쏠림을 대신 보는 지표로 쓴다. 매매 시뮬레이션은 그대로 비트겟 캔들로 한다. |
| 미래 정보 차단 | 1시간봉(시작 t)의 값은 봉이 끝나는 t+1h에 알 수 있던 것만 쓴다. 5분 스냅샷과 펀딩 정산도 그 시각보다 **엄격히 이전** 것만 쓴다. 이동 통계는 모두 과거 방향이다. 뒤에 데이터를 붙여도 앞 값이 안 바뀌는지 검사한다(`test_phase_c.py`). |

| 학습 구간 | 2차 FreqAI와 같다. 2023-10-01부터 90일씩 예측하고, 각 모델은 그 직전 365일로만 학습한다. 라벨 48시간이 예측 시작 전에 끝난 행만 학습에 쓴다. |

**결과를 본 뒤 추가한 것** (미리 정한 규칙 밖이라 따로 표시):
- **코인별 대조군 (`*_pc`)**: 코드 검토에서 "통합 모델이 진입 신호 자리의 순위를 뒤집는다"는 지적이 나와서 추가했다. 데이터·특징·구간·보정은 같고, 2차처럼 코인마다 모델을 따로 만든다. 묶음 효과와 데이터 효과를 따로 재기 위한 것이다.
- **신호 자리만 학습 (`*_sig`, 탐색용)**: 통합 모델에서 신호 자리 판별력이 0.5 아래로 나오자 시도했다. 학습 행을 진입 신호가 난 자리로만 한정했고, 백테스트는 하지 않았다.

## 한 줄 요약

**포지션 데이터(펀딩·OI·롱숏)를 넣고 코인을 10개로 늘려도 실전 근거는 나오지 않았다.**
- 전체 행 판별력은 0.524에서 0.531~0.532로 조금 올랐다.
- 실제 진입하는 자리에서는 통합 모델이 0.45~0.48로 동전 던지기 이하였다. 지표·지표+사건 모델은 90% 범위 상한도 0.5 미만이다.
- 코인별 모델은 0.52~0.53으로 2차와 같은 수준이었고, 포지션 데이터를 넣어도 오르지 않았다(0.531에서 0.527).
- 돈으로는 17개 실행 중 몇 개가 플러스였다. 가장 좋은 두 개(+13.8%, +12.1%)도 수익의 대부분이 ADA 거래 몇 건에서 나왔고, 2025년 이후는 0 근처다.
- 달력 표시 24개만 고쳐도 일부 실행의 수익이 7~10%p씩 바뀌었다. 결과가 잡음에 크게 흔들린다는 뜻이다.
- 같은 3년 BTC 보유는 +204%였다.

## 결과 (표본 외 2023-10-01 ~ 2026-10-20)

- **묶음 효과**: 같은 데이터로 코인별 모델을 만들면 신호 자리 AUC가 0.52~0.53이다. 2차(코인 5개, 코인별 FreqAI, 보정 전 p) 0.524~0.538과 같은 수준이다. 2차 코인 5개만 떼어 봐도 코인별 0.521~0.529, 통합 0.427~0.477이었다. 통합 모델이 신호 자리를 망친 것이다.
- **포지션 데이터 효과**: 전체 행에서는 +0.005~0.008이다. 신호 자리에서는 코인별 기준 0.531에서 0.527로 차이가 없다. 포지션 특징은 모델 안에서 자주 쓰였지만(`ind_der` 분할 이득의 52~53%), 진입 자리의 승패를 가르지는 못했다.
- **확률 보정**: 보정한 p의 Brier 점수가 학습 기저율을 그대로 쓴 상수보다 나빴다(통합 0.2210~0.2222 vs 0.2208, 코인별 0.2231~0.2235 vs 0.2213). 확률값 자체는 정보가 없다.
- **통합 모델의 p**: 신호 자리에서 거의 0.5를 넘지 못했다. 발표 회피 밖에서 p≥0.5인 신호는 `ind` 1개, `ind_ev` 0개, `all` 3개, `ind_der` 8개(적중 12%)뿐이다.
- **코인별 모델의 p**: p≥0.5 신호는 40~62개이고 적중률은 46~52%다(기저 39.5%). 그런데 `ind_der`는 0.45→0.5→0.55→0.65로 갈수록 57%→47%→44%→42%로 오히려 떨어진다. 순위가 안정적이지 않다.
- 중요했던 특징(통합 `all`): 다음 주요 발표까지 남은 시간 0.127, BTC 전체 계정 롱숏 0.107, 일봉 추세 0.086, ATR 순위 0.060, ATR 비율 0.055, EMA200 거리 0.052, 3일 평균 펀딩 0.051. 코인별 `all`에서는 일봉 추세, 발표까지 시간, ATR, 3일 평균 펀딩, ADX, OI 30일 z, EMA200 거리 순이었다.

### 다. 가장 좋아 보이는 `filter_ind_der_pc` (+13.8%)와 `filter_all_pc` (+12.1%) 점검

- 미리 정한 실험이 아니다. 검토 뒤 추가한 대조군이고, 17개 실행 중 가장 좋은 하나를 고른 것이라 우연을 의심해야 한다.
- 순수익 14.5 USDT 중 ADA 8건이 13.5 USDT다. 가장 큰 3건을 빼면 마이너스다(상위 3건 비중 116%).
- 연도별로는 2023년(4분기) +7.6%, 2024년 +6.0%, 2025년 -0.5%, 2026년 +0.3%다. 최근 2년은 0 근처다.
- 거래 단위 부트스트랩(1만 번)에서 합계가 0 이하일 확률은 9.7%다. 5% 기준을 넘지 못한다.
- 같은 모델에 등급 규칙을 쓰면 +1.4%다. 같은 데이터로 규칙만 바꿨는데 재현되지 않는다.
- `filter_all_pc`도 같은 모양이다. 12.7 USDT 중 ADA가 13.0 USDT, 상위 3건 비중 125%, 부트스트랩에서 0 이하일 확률 13.1%다. 2023년 +9.9% 뒤로는 +1.6%, +0.4%, -0.1%다.
- 달력 보정 전후로 `filter_all_pc`는 +5.4%에서 +12.1%로, `tiered_ind_ev_pc`는 -4.1%에서 +5.7%로 바뀌었다. 입력이 조금만 달라져도 크게 흔들린다.
- 판단: 쓸 만한 우위가 아니라 표본이 작은 데서 나온 운으로 본다. 모의 운용 관찰 후보로만 기록한다.

### 라. 설계서 §18 승격 규칙 판정

- 미리 정한 통합 모델은 8개 실행 모두 기준 전략(+6.9%)을 이기지 못했다. 플러스인 3개(+1.5%, +0.6%, +0.4%)도 거래가 5건, 18건, 14건뿐이라 근거가 되지 않는다. **불합격**이다.
- 코인별 대조군 중 플러스 변형이 있지만 사후 선택이고 강건성 점검에서 실패했다. **불합격**이다.
- 실전(또는 실전용 모의 운용)으로 올릴 전략은 없다.

## 코드 검토 (실행 결과를 믿기 전에)

**1차 검토**: 리뷰어 4명이 차원별로 찾고, 지적마다 반박자 2명이 검증했다.

| BTC·ETH 항상 포함 규칙이 강제되지 않음 (작음) | 사실 | 빠지면 멈추게 수정 |
| 문턱값 개수가 발표 회피를 무시함 (작음) | 사실 | 발표 회피 밖 개수를 따로 보고 |

**미래 정보 누출 재검토** (1차에서 이 부분 리뷰어가 결과를 내지 못해 다시 했다. 세 각도를 따로 보는 리뷰어 3명이 코드를 읽고 실제 데이터로 확인했다):
- **포지션 특징**: 10개 코인에서 26개 행씩, 18개 특징 4,680개 값을 원자료로 손계산해 비교했다. 차이는 0이다(최대 상대오차 1.7e-10).
- **데이터 자르기 비교**: 10개 시점(구간 경계, 4시간봉 중간, 2026-08 빈 봉 주변 포함)에서 데이터를 자른 것과 전체 데이터로 만든 것을 비교했다. 지표·신호·포지션·사건 특징 모두 일치했다.
- **바이낸스 5분 자료의 시각**: 구간 **시작** 시각이 찍혀 있다(t+55분 자료가 t+1h까지를 담는다). 봉 마감 시각에 찍힌 자료를 쓰지 않는 현재 규칙이 맞다. 펀딩 정산 시각도 정시 이후로만 찍힌다.
- **학습 구간 경계**: 13개 구간 모두 학습 행 + 49시간이 예측 시작 이전이다. 보정용 구간과 학습 구간 사이는 2일 4시간 떨어져 있다. 예측 구간 행은 학습에 들어가지 않는다(통합·코인별 모두).
- **백테스트 진입 시점**: Freqtrade 2026.9 소스를 확인했다. 행 t의 신호는 다음 봉(t+1h) 시가에 체결되고, 전략이 보는 데이터는 직전 봉까지다. 예측 파일에는 (코인, 시각)마다 p가 하나씩만 있고, 2023-10-01 이전이나 2026-10-20 이후 값은 없다.
- **발견 1건 (작음)**: 사건 달력에서 2주 전에는 알 수 없던 사건 24개에 "예정된 일정" 표시가 붙어 있었다. 휴전, 위원회 결과, 탄핵 표결·선고, 정상회담, 거래소 폐업, 2025년 셧다운으로 날짜가 바뀐 미국 지표가 여기에 해당한다. 사건 특징을 쓰는 `ind_ev`·`all`의 OOS 행 약 2~3%가 영향을 받았다. 원본 달력은 그대로 두고, 이 24개만 일정 아님으로 고친 사본(`calendar_fix_c.py` → `events_c.csv`)을 만들었다. 3차 실험은 사건 특징에 그 사본을 써서 전부 다시 돌렸고, 위 표가 그 결과다.
- **최종 점검** (커밋 전 리뷰어 2명): README 숫자 255개를 결과 파일과 대조했고, 틀린 문구 3곳을 고쳤다. 코드 지적은 2건이다.
  - 달력 보정이 발표 전후 진입 금지(§7.1)에서도 실제 미국 발표 5건을 빼 버렸다. 날짜가 바뀐 발표도 며칠 전에는 공개돼 있었으므로 진입 금지에는 원본 달력을 써야 한다. 그렇게 고쳤다. 확인해 보니 차이가 나는 200개 시간 행 중 진입 신호 자리는 12개 예측 파일 모두 0개였다. 그래서 평가 숫자와 백테스트 결과는 바뀌지 않는다.
  - 실패한 백테스트를 분석이 건너뛰지 못하고, 실행 스크립트가 실패해도 0으로 끝났다. 둘 다 고쳤다(현재 17개 실행은 모두 성공).
- 남은 한계: 셧다운으로 취소된 원래 일정(2025-10-03 NFP, 10-15 CPI)은 달력에 없다. 그래서 2025-10-01 직전 며칠은 이 발표를 앞둔 것으로 보이지 않는다. 2차 실험도 같은 원본 달력을 썼으므로 2차의 사건 변형도 같은 정도로 약간 낙관적이다.

## 이 실험의 주의사항

- **생존 편향**: 오늘 살아남은 상위 코인을 과거에 적용했다.
- **바이낸스 대용**: 포지션 데이터는 바이낸스 것이다. 비트겟의 실제 쏠림과는 다를 수 있다.
- **롱숏 데이터 빈 곳**: 바이낸스 롱숏 칸 일부가 비어 있다. 전체 기간 기준 상위 트레이더 칸은 82%만 채워졌고, 빈 곳은 주로 2022년에 있다. 첫 학습 구간(2022-10~2023-10) 일부가 영향을 받는다. 빈 값은 LightGBM이 그대로 처리했다.
- **여러 번 비교**: 17개 실행과 4×3 모델을 봤다. 가장 좋은 하나는 우연히 좋게 나올 수 있다.
- **사후 추가**: 코인별 대조군과 신호 자리 학습은 결과를 본 뒤 추가했다.
- **같은 라벨·같은 진입 규칙**: 다른 진입 방식(예: 신호 없이 p만으로 진입)은 시험하지 않았다. 새 규칙을 같은 데이터에서 찾으면 과최적화가 된다.

## 다시 돌리는 방법

```bash
# worktree 루트, Git Bash. `up`은 쓰지 않는다. 공개 데이터만 쓴다.
export MSYS_NO_PATHCONV=1
P="-p bitget-spike -f freqtrade/docker-compose.yml"
F="$P -f research/2026-10-20-90d-backtest/compose.freqai.yml"
R="-v $(pwd -W)/research/2026-10-21-derivs:/research -v $(pwd -W)/research/2026-10-20-90d-backtest:/research_b"
docker compose $P run --rm $R --entrypoint python freqtrade -P /research/select_pairs_c.py
docker compose $P run --rm freqtrade download-data --config /freqtrade/user_data/config.backtest.json --pairs ADA/USDT:USDT UNI/USDT:USDT LINK/USDT:USDT AVAX/USDT:USDT DOGE/USDT:USDT --timeframes 1h --candle-types futures mark funding_rate --timerange 20220101-20261020 --prepend
docker compose $F run --rm $R --entrypoint python freqai -P /research/fetch_binance.py
docker compose $P run --rm -v "$(pwd -W)/research:/research_all" --entrypoint python freqtrade -P /research_all/2026-10-21-derivs/calendar_fix_c.py   # events_c.csv
docker compose $P run --rm $R --entrypoint python freqtrade -P /research/make_zero_funding_c.py
docker compose $F run --rm $R --entrypoint python freqai -P /research/test_phase_c.py
for m in all_rows per_coin signal_rows; do docker compose $F run --rm $R --entrypoint python freqai -P /research/walkforward_c.py $m; done
bash research/2026-10-21-derivs/run_phase_c.sh
docker compose $F run --rm $R --entrypoint python freqai -P /research/analyze_c.py
```
